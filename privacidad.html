Política de privacidad

Última actualización: 28 de octubre de 2026 · English below

Esta política explica qué datos trata Alkemi y su herramienta de publicación. Responsable: Alkemi, alkemi.videos@gmail.com.

Qué es la herramienta

Una herramienta propia de Alkemi que funciona solo en el ordenador de su autor. Sirve para subir los vídeos de Alkemi a las cuentas de Alkemi (una por idioma). No es una aplicación pública y no la usa nadie más.

Servicios de API de YouTube

La herramienta usa los servicios de API de YouTube. Al usarla se aceptan las Condiciones de servicio de YouTube, y se aplica la Política de privacidad de Google.

Qué datos usa

  • Permiso para subir vídeos al canal de YouTube que su titular autoriza.
  • El nombre y el identificador del canal, solo para comprobar que el vídeo va al canal correcto.

No lee, guarda ni analiza datos de espectadores, comentarios, estadísticas ni de ninguna otra persona.

Dónde se guardan

El permiso (el token de acceso de Google) se guarda únicamente en el ordenador del autor, en un archivo que solo él puede leer. No se envía a ningún servidor propio ni a terceros, y no se comparte, vende ni transfiere.

Esta web

No usa cookies, analítica ni formularios, y no recoge ningún dato de quien la visita.

Cómo retirar el permiso y borrar los datos

El titular de la cuenta puede retirar el acceso en cualquier momento desde la página de permisos de seguridad de Google. Al retirarlo, el token deja de valer y se borra del ordenador. Para cualquier consulta o para pedir que se borre algo: alkemi.videos@gmail.com.

Cambios

Si esta política cambia, se publicará aquí con su nueva fecha.

Privacy policy (English)

Last updated: October 28, 2026. Controller: Alkemi, alkemi.videos@gmail.com.

What the tool is

Alkemi's own publishing tool runs only on its author's computer and uploads Alkemi's videos to Alkemi's own accounts (one per language). It is not a public application and nobody else uses it.

YouTube API Services

The tool uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

Data used

  • Permission to upload videos to the YouTube channel its owner authorizes.
  • The channel name and ID, only to check that each video goes to the right channel.

It does not read, store or analyze data about viewers, comments, analytics or any other person.

Storage and sharing

The authorization (the Google OAuth token) is stored only on the author's computer, in a file only they can read. It is never sent to any other server and is never shared, sold or transferred to third parties.

This website

No cookies, analytics or forms. It collects no data from visitors.

Revoking access and deleting data

The account owner can revoke access at any time through the Google security settings page. Once revoked, the token stops working and is deleted from the computer. For any question or deletion request: alkemi.videos@gmail.com.

Changes

Any change to this policy will be published here with its new date.
